# 🗺 NLW Journey ReactJS Planner

## Sobre o projeto

Este é um planejador de viagens **desktop/web**, desenvolvido durante o NLW Journey da Rocketseat com React, TypeScript e Vite.  
Permite criar roteiros de viagem com amigos, adicionar atividades e links úteis, além de convidar participantes para colaborar no plano.

## ✨ Funcionalidades principais

- Criar uma nova viagem com local, datas e participantes
- Compartilhar convites com outras pessoas
- Adicionar e visualizar atividades da viagem
- Salvar links úteis relacionados ao planejamento
- Interface moderna, limpa e responsiva

## 🧰 Tecnologias utilizadas

- **React** com **Vite**
- **TypeScript**
- **Tailwind CSS** (com Variants)
- **Zustand** para gerenciamento de estado global
- **React Query** para chamadas assíncronas
- **React Router DOM** para rotas
- **Radix UI** e **Radix Icons**
- **React Day Picker**, **date-fns**
- **Axios** para requisições HTTP
- **Sooner** (UI framework)

> ℹ️ A API (backend) do projeto está em outro repositório.

## 🖥️ Pré-requisitos

Antes de começar, você precisa ter instalado:

- Git  
- Node.js  
- npm ou Yarn  
- (Opcional) VS Code

## 🚀 Como executar o projeto

```bash
# Clone o repositório
git clone https://github.com/Sh4rk-dev/NLW-Journey-ReactJS-Planner.git

# Acesse a pasta do projeto
cd NLW-Journey-ReactJS-Planner

# Instale as dependências
npm install
# ou
yarn install

# Inicie o servidor de desenvolvimento
npm run dev
# ou
yarn dev
```
